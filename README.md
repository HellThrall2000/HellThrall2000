## 🚀 Projects

### 🧘 [SanctuAIry](https://github.com/HellThrall2000/sanctuairy-app)
Privacy-first, cross-platform mental wellness app running a **fine-tuned Gemma model fully on-device** via LiteRT-LM — zero cloud dependency, zero data leaving the device.
- Fine-tuned Gemma with **LoRA/PEFT + 4-bit quantization** on multi-GPU (DDP), exported to LiteRT-LM
- Local **RAG architecture** (vector search, fact extractors, semantic chunking) for continuous conversational memory
- Custom Flutter plugin for fully offline on-device LLM inference

`Flutter` `LiteRT-LM` `Dart` `Firebase` `Vector DB`

---

### 📦 [OptiChain-Env](https://github.com/HellThrall2000/OptiChain-Env)
A **Meta OpenEnv-compliant** supply chain simulation built for a 2026 hackathon — LLM agents manage inventory across a 30-day stochastic episode.
- **Planner → Executor → Guardrails** multi-agent pipeline converting LLM reasoning into structured JSON actions
- Real-time FastAPI dashboard visualizing agent reasoning and per-step rewards
- Deployed on Hugging Face Spaces via Docker

`Python` `FastAPI` `Meta OpenEnv` `Docker` `HF Spaces`

---

### 📊 [Xcelord](https://github.com/HellThrall2000/Xcelord)
AI-powered spreadsheet assistant — natural language *and voice* commands to query, filter, and transform Excel data.
- **LLM-to-Pandas** code-generation and execution pipeline (Groq) with safe, reversible operations
- Voice input with auto-transcription and real-time AG Grid editing, with live save-back to `.xlsx`

`Python` `Streamlit` `Groq` `Pandas` `OpenPyXL`
